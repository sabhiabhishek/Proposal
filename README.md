## 🚀 Deployment to GitHub Pages

### Step 1: Create a GitHub Repository

1. Go to [GitHub](https://github.com) and sign in
2. Click the "+" icon in the top right corner
3. Select "New repository"
4. Name your repository (e.g., `ask-sonali-out`)
5. Make sure it's **Public**
6. Click "Create repository"

### Step 2: Upload Your Files

**Option A: Using Git (Recommended)**

```bash
# Navigate to your project folder
cd path/to/your/ask-her-out-website

# Initialize git repository
git init

# Add all files
git add .

# Commit your files
git commit -m "Initial commit: Asking Sonali to be my girlfriend 💕"

# Add your GitHub repository as remote
git remote add origin https://github.com/YOUR-USERNAME/ask-sonali-out.git

# Push to GitHub
git branch -M main
git push -u origin main
```

**Option B: Using GitHub Web Interface**

1. On your repository page, click "uploading an existing file"
2. Drag and drop all project files (`index.html`, `styles.css`, `script.js`)
3. Click "Commit changes"

### Step 3: Enable GitHub Pages

1. In your repository, go to **Settings** (top menu)
2. Scroll down to **Pages** (left sidebar)
3. Under "Source", select **main** branch
4. Click **Save**
5. Wait a few minutes for deployment
6. Your site will be live at: `https://YOUR-USERNAME.github.io/proposal-for-sonali/`

### Step 4: Share the Link

Once deployed, share the URL with Sonali when you're ready! 💕

## 🎨 Customization Options

Edit `styles.css` and modify the CSS variables:

```css

    --accent-primary: #ff6b9d;      /* Main pink color */
    --accent-secondary: #c792ea;    /* Purple accent */
    --accent-tertiary: #82aaff;     /* Blue accent */
    /* ... more colors ... */
}
```

### Add Background Music

1. Add your music file (e.g., `music.mp3`) to the project folder
2. Uncomment and update the audio source in `index.html`:

```html
<audio id="bgMusic" loop>
    <source src="music.mp3" type="audio/mpeg">
</audio>
```

3. Make sure the music file is also uploaded to GitHub

## 🔧 Troubleshooting

### Site Not Loading?
- Wait 5-10 minutes after enabling GitHub Pages
- Check that files are in the root directory (not in a subfolder)
- Ensure repository is Public

### Animations Not Working?
- Clear browser cache (Ctrl+F5 or Cmd+Shift+R)
- Try a different browser
- Check browser console for errors (F12)

### Music Not Playing?
- Browsers require user interaction to play audio
- Click the music toggle button (top right)
- Make sure music file is properly uploaded
